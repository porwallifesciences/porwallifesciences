# Porwal Life Sciences Website

Static GitHub Pages website for Porwal Life Sciences.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Enquiry form
The form uses FormSubmit and is configured for info@porwallifesciences.com. The first submission may trigger a one-time activation/confirmation email from FormSubmit. After activation, form submissions are forwarded to the business email. This is a third-party service; no private API key is stored in the repository.

## Custom domain
After GitHub Pages is working, set the custom domain to porwallifesciences.com. DNS records at Hostinger should then be configured according to GitHub Pages' current instructions.
